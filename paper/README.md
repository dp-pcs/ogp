## Compilation

Requires a LaTeX distribution (TeX Live or MacTeX) and the ACM `acmart` class.

```bash
# Install acmart if not already present
# https://www.acm.org/publications/proceedings-template

pdflatex hotnets2026.tex
bibtex hotnets2026
pdflatex hotnets2026.tex
pdflatex hotnets2026.tex
```

Or with `latexmk`:

```bash
latexmk -pdf hotnets2026.tex
```

## Benchmark Data

Benchmark results cited in Section 6 are generated by:

```bash
node ../bench/ogp-bench.mjs
# Output: ../bench/results.json
```

The paper cites numbers from a run on Apple M4 Pro (Node.js v26.3.0).
Re-running on different hardware will produce different absolute numbers
but the same qualitative result (sub-millisecond overhead at every layer).
